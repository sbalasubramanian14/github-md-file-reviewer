How to use

  1. Open any PR with .md files
  2. Click the purple MD Review button (bottom-right)
  3. Browse rendered markdown with the file selector
  4. Hover any element and click 💬 to comment
  5. View, reply, edit, or delete comments in the sidebar
Works on any github.com/*/pull/* page
